# prql-java

`prql-java` offers Java bindings to the `prqlc` Rust library, through
[JNI](https://docs.oracle.com/javase/8/docs/technotes/guides/jni/). It exposes
three native methods on `org.prql.prql4j.PrqlCompiler`:

```java
public static native String toSql(String query, String target, boolean format, boolean signature) throws Exception;
public static native String toJson(String query) throws Exception;
public static native String format(String query) throws Exception;
```

`target` is a dialect name such as `sql.mysql` — see
[Target and version](https://prql-lang.org/book/project/target.html) for the
full list. `format` controls whether the SQL is pretty-printed, and `signature`
whether the trailing `-- Generated by PRQL compiler version:...` comment is
included.

It's still at an early stage, and currently requires compiling locally, and
isn't published to Maven. Contributions are welcome.

## Installation

Build the bindings and install them into your local Maven repository from
`java/`:

```sh
./mvnw install
```

Then depend on the coordinates declared in
[`java/pom.xml`](https://github.com/PRQL/prql/blob/main/prqlc/bindings/java/java/pom.xml)
— note that its `<version>` is maintained separately from the PRQL release
version, and is not currently bumped on release
([#850](https://github.com/PRQL/prql/issues/850)):

```xml
<dependency>
    <groupId>org.prqllang</groupId>
    <artifactId>prql-java</artifactId>
    <version>0.5.2</version>
</dependency>
```

## Usage

```java
import org.prql.prql4j.PrqlCompiler;

class Main {
    public static void main(String[] args) throws Exception {
        String sql = PrqlCompiler.toSql("from my_table", "sql.mysql", true, true);
        System.out.println(sql);
    }
}
```

See
[DEVELOPMENT.md](https://github.com/PRQL/prql/blob/main/prqlc/bindings/java/DEVELOPMENT.md)
for how the bindings are built.
